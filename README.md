# Задание 2.1 — Приложение для рисования

## Описание
iOS-приложение на Objective-C для рисования линиями с выбором цвета и размера кисти. Реализовано сохранение рисунка в библиотеку фото.

## Функциональность
- Рисование произвольных линий
- 5 размеров кисти: 2, 5, 10, 15, 20 pt (Slider)
- 5 цветов: красный, синий, зелёный, чёрный, жёлтый (Segmented Control)
- Кнопка «Сохранить» — сохранение в фото
- Кнопка «Очистить» — очистка холста

## Структура проекта (КИС для Objective-C)
- `DrawView.h` / `DrawView.m` — интерфейс и реализация класса для рисования
- `ViewController.h` / `ViewController.m` — контроллер, управление элементами
- `Main.storyboard` — интерфейс

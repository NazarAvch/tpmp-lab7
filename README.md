# Задания 2.2–2.4 — Графические объекты, анимации, жесты

## Описание
iOS-приложение на Swift с архитектурой MVC, иллюстрирующее объекты двумерной графики (звезда, круг) с градиентом и тенью, анимациями и обработкой жестов.

## Функциональность

### 2.2 — Графические объекты
- Пятиконечная звезда
- Круг
- Вычитание фигур (звезда минус круг, круг минус звезда)
- Объединение фигур (звезда + круг)
- Однотонный фон, градиент, тень

### 2.3 — Анимации
- Перемещение (Move)
- Вращение (Rotate)
- Масштабирование (Scale)
- Прозрачность (Alpha)
- Комбинация (Move + Rotate)

### 2.4 — Жесты
| Жест | Фон фигуры |
|------|-----------|
| Вращение (Rotation) | Красный |
| Масштабирование (Pinch) | Синий |
| Касание (Tap) | Зелёный |
| Долгое нажатие (Long Press) | Оранжевый |
| Смахивание (Swipe) | Фиолетовый |

## Структура проекта (MVC)
- `Model/ShapeModel.swift` — модель данных фигуры
- `View/ShapeView.swift` — отрисовка фигур
- `Controller/ShapeViewController.swift` — управление, анимации, жесты
